# Vibemessanger

Простой веб-мессенджер в реальном времени.

## Возможности

- Регистрация по нику
- Список онлайн-пользователей
- Личные чаты в реальном времени (Socket.IO)
- История сообщений

## Стек

- Node.js + Express
- Socket.IO
- Vanilla JS (frontend)

## Запуск

    npm install
    node server.js

Открыть http://localhost:3000
